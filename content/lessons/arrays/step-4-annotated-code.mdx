<AnnotatedCode
  language="python"
  title="Find the Largest Value"
  code={`def find_max(values):
    if not values:
        return None

    largest = values[0]
    for index in range(1, len(values)):
        if values[index] > largest:
            largest = values[index]

    return largest`}
  annotations={{
    1: "Define a function that accepts the array.",
    2: "Handle the empty-array case before indexing.",
    3: "There is no maximum when the input is empty.",
    5: "Use the first value as the initial maximum.",
    6: "Visit every remaining index once.",
    7: "Compare the current value with the best seen so far.",
    8: "Update the maximum only when a larger value is found.",
    10: "Return the largest value after the traversal.",
  }}
/>

<Callout type="info">
  Starting with <code>values[0]</code> is safe because the function checks for an empty array first. Without that check, indexing an empty array would fail.
