<AnnotatedCode
  language="python"
  title="Count Frequencies"
  code={`def count_frequencies(values):
    counts = {}
    for value in values:
        counts[value] = counts.get(value, 0) + 1
    return counts`}
  annotations={{
    1: "Accept the sequence to count.",
    2: "Start with an empty dictionary.",
    3: "Process each input value once.",
    4: "Read its current count, default to zero, then store the incremented count.",
    5: "Return the completed frequency map.",
  }}
/>

---

<Callout type="info">
  <code>dict.get(key, default)</code> returns the stored value when the key exists; otherwise it returns the default without raising a missing-key error.
</Callout>
